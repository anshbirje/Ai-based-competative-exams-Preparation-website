# **App Name**: StudySage

## Core Features:

- AI Note Generation: Users can input topics/keywords or upload images/PDFs for the AI tool to process, analyze, and generate concise, structured study notes automatically.
- Subject-wise Organization: Allows users to save, categorize, and organize their generated notes by subject for easy retrieval and management.
- Flashcard Review Mode: Transforms study notes into interactive flashcards for effective memorization and active recall, including a review interface.
- Document Upload Interface: Provides an intuitive interface for uploading images and PDF documents to be processed for note generation.
- Note Editing and Refinement: Enables users to review, edit, and refine the AI-generated notes to personalize and improve their study material.
- User Authentication: Secure user registration and login functionality to save and access personalized study notes across sessions.

## Style Guidelines:

- Primary color: Muted, calming green (#559933) to foster focus and academic intent, chosen for its gentle presence rather than vibrancy.
- Background color: A very subtle, off-white with a hint of green (#F2F4F0) to maintain a clean and airy, distraction-free environment while adhering to the specified 'white' scheme.
- Accent color: A brighter, more energetic yellowish-green (#BEE442) for interactive elements and highlights, providing contrast and drawing attention when needed without being overly disruptive.
- All text: 'Inter', a clean and highly readable sans-serif font suitable for both headlines and body text, supporting a modern and distraction-free aesthetic essential for a study aid.
- Use minimalist, line-based icons that convey their meaning clearly and quickly without clutter, aligning with the clean and focused UI.
- Adopt a structured, two-column layout where content is easily navigable, featuring generous whitespace to enhance readability and reduce cognitive load during study sessions.
- Incorporate subtle and functional animations, such as smooth transitions for navigating notes or flipping flashcards, to guide user interaction without causing distraction.
